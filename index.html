Terminal-based expense tracker with local SQLite persistence, installments, shared expenses, and full CRUD. AI-powered analysis and automatic categorization coming next. Built with Ink + React, Bun, TypeScript, and a multi-agent AI development workflow.

About the Project

What is Expense Tracker AI and why it exists.

🎯

Purpose

Track personal expenses and automatically categorize them using AI. Get insights, spot trends, and make smarter financial decisions.

🤖

AI-First Development

Built using a multi-agent AI harness (.harness/) where specialized agents collaborate: an orchestrator plans, a developer codes, and a tester validates.

📐

Simple by Design

The project intentionally keeps its harness minimal. The goal is to understand how AI-agent architecture works in practice, without over-engineering.

Tech Stack

The technologies that power this project.

⚡

Bun

JavaScript runtime and package manager. Used as a drop-in replacement for Node.js and npm.

Runtime Package Manager
📘

TypeScript

Strict type-checking enabled. No any types allowed. Explicit typing for all public APIs.

Strict Mode Type Safety
🖥️

Ink + React

Component-based TUI framework. Declarative terminal interfaces with React components and JSX.

TUI Terminal
🗄️

SQLite

Local persistence via Bun's native bun:sqlite. No server, zero setup, stored in .data/expenses.db.

Persistence Local
🧠

AI Agents

Multi-agent system with orchestrator, developer, tester, and reviewer roles working in concert.

Branch Naming Convention

Consistent, professional branch naming used across the repository.

Format

<type>/<number>-<short-description>

Types

Type Usage
feat New feature
bug Bug fix
chore Maintenance (deps, config)
refactor Code refactoring, no functional change
docs Documentation changes

Examples

feat/001-add-new-column bug/002-remove-unused-variable chore/003-update-bun-deps refactor/004-rename-user-service docs/005-update-readme
